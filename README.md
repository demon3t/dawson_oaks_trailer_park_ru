# Русификатор Dawson Oaks Trailer Park

Добавляет в игру [Dawson Oaks Trailer Park](https://store.steampowered.com/app/3640200/Dawson_Oaks_Trailer_Park/) русский язык.
Переведены меню, настройки, роли, позывы, подсказки, предметы, телефон и обучение.

## Как установить

1. Нажмите зелёную кнопку **Code** вверху страницы и выберите **Download ZIP**.
2. Распакуйте архив в любую папку.
3. Закройте игру, если она запущена.
4. Запустите **`install.bat`** и дождитесь надписи «Готово!».
5. Запустите игру. Если язык не переключился сам, выберите его вручную:
   **Settings → Game → Language → Русский**.

Готово, можно играть!

## Как удалить

Запустите **`uninstall.bat`**. Игра вернётся к исходному состоянию.

## Если что-то пошло не так

- **«Игра не найдена»**: перетащите папку игры мышкой прямо на файл `install.bat`.
  Найти папку можно в Steam: правый клик по игре → **Управление** → **Просмотреть локальные файлы**.
- **«Файл не подходит к этой версии русификатора»**: игра обновилась. Дождитесь обновления
  русификатора и скачайте его заново.
- **После обновления игры пропал русский язык**: это нормально, Steam заменяет файлы игры.
  Скачайте свежую версию русификатора и снова запустите `install.bat`.
- **Игра сломалась**: запустите `uninstall.bat` или в Steam: правый клик по игре →
  **Свойства** → **Установленные файлы** → **Проверить целостность файлов игры**.

## Важно

- Это неофициальный фанатский перевод.
- Русификатор меняет только язык интерфейса, остальные языки игры остаются на месте.
- Нашли ошибку в переводе или текст не помещается? Создайте issue со скриншотом.
